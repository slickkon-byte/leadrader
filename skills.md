# Project Skills & Development Rules

## Core Rule: Beginner-Friendly Code Documentation
- **Plain English Explanations**: Always add beginner-friendly comments to every block of code and explain what the code does in plain English.
- **No Complex Jargon**: When explaining logic, functions, or configurations, use simple real-world analogies (like a digital postman, a filing cabinet, or a recipe).
- **Clear Structure**: Keep code organized in small, digestible pieces that are easy to follow and understand.
